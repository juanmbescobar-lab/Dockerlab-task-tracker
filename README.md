# DockerLab Task Tracker

Mini plataforma web full-stack creada con fines educativos para aprender Docker, Docker Compose y buenas prácticas con Git.

## Tech Stack
- Frontend: HTML, CSS, JavaScript (Nginx)
- Backend: Node.js + Express
- Database: PostgreSQL
- Docker & Docker Compose

## Objetivo
Aprender a:
- Crear y usar imágenes Docker
- Ejecutar contenedores con docker run
- Orquestar servicios con Docker Compose
- Conectar múltiples contenedores entre sí
